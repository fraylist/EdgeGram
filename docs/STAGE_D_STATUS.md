# Stage D — статус

- Ветка: `stage-d`. Последний коммит: см. `git log -1 --oneline`.
- Сделано: хранение `kept_dialogs` (БД v4, колонка `channel`), перехват `kicked`/`banned`/`channelForbidden`/`chatForbidden`,
  восстановление при ре-синке (синтетический `TL_dialog`: `flags`, `peer`, `last_message_date`, проверка кэша),
  read-only `ChatActivity` (баннер, скрытая панель ввода), экран «Сохранённые чаты» с «Удалить окончательно».
- НЕ проверено на устройстве:
  * открытие kept-чата (история, баннер, отсутствие ввода);
  * шапка при `getChat(-did) == null`;
  * баннер и кнопка «вниз» (z-order);
  * отсутствие сети: `logcat getMessages|getChannelDifference|CHANNEL_PRIVATE`.
- Четыре сценария:
  1) канал удалён с другого аккаунта → kept, история читается;
  2) выкинули из группы → kept;
  3) сам вышел из группы → диалог исчезает (не kept);
  4) «Удалить чат» на kept → исчезает навсегда, ре-синк не возвращает.
- Запрещено до проверки: мерж в `main`, тег, тумблер `keepDialogs` по умолчанию вкл.
