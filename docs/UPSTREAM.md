# Синхронизация с апстримом

Апстрим: https://github.com/DrKLO/Telegram, ветка `master`.
Тегов после `release-11.4.2-5469` нет, поэтому версию определяем по `APP_VERSION_NAME`
в `gradle.properties`, а точку синхронизации фиксируем по SHA в `docs/UPSTREAM_BASE.txt`.

Текущая база: `21f7d109da6ab3506c9e9577f98c6a38771ab335` — «update to 13.2.2 (7303)».

## Правила

1. Мержим каждый релиз апстрима, не пропускаем. Мелкий мерж — час, крупный — неделя.
2. Своя логика живёт в `Edge*`-классах; в чужих файлах — только однострочные вызовы.
3. Ветки `sync/upstream-<sha8>` создаются автоматически, правятся руками, мержатся через PR.
4. `git config rerere.enabled true` — разрешённые конфликты применяются повторно.

## Ритуал

1. Дождаться PR «Sync upstream: <sha>» или запустить workflow `Sync upstream Telegram` руками.
2. `git fetch origin && git checkout sync/upstream-<sha8>`
3. `./gradlew :TMessagesProj_App:assembleAfatRelease -PedgeAbi=arm64-v8a`
4. Прогнать чек-лист ниже на устройстве.
5. Смержить PR, поднять `APP_VERSION_CODE`, выпустить релиз.

## Чек-лист после каждого мержа

- [ ] keepTtl: фото с таймером 10 с не исчезает; после перезапуска тоже
- [ ] keepDeleted: удалённое сообщение остаётся с меткой
- [ ] keepEdits: история правок открывается
- [ ] allowRestricted: сохранение в защищённом чате работает
- [ ] secretFree: скриншот в секретном чате без уведомления
- [ ] ghost: сообщение не отмечается прочитанным
- [ ] Скрытый режим: второй код открывает подставной аккаунт
- [ ] Биометрия на чаты: запрос при открытии, повторная блокировка после выхода
- [ ] Уведомления: keep-alive, wake lock и досинхронизация работают
- [ ] OTA: проверка обновлений находит манифест
- [ ] PIN: вход по коду, duress-код, очистка после 10 ошибок
- [ ] arm64 и universal ставятся на чистое устройство
