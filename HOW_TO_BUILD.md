# Как собрать EdgeGram самому

Это пошаговая инструкция для новичка. Читай по порядку и делай ровно то, что написано. Ничего страшного, если что-то пойдёт не так: в конце есть раздел «Если сломалось».

Собрать можно двумя способами:

- **Способ 1 — без компьютера.** Всё сделает GitHub в браузере. Это самый простой путь, начни с него.
- **Способ 2 — на своём компьютере.** Дольше, но зато ты сам собираешь APK и можешь менять что угодно.

---

## Способ 1: собрать в браузере (5 минут)

Тебе понадобится только браузер и аккаунт GitHub.

1. Открой https://github.com/fraylist/EdgeGram/actions
2. Слева нажми синюю надпись **Build APK**.
3. Справа появится кнопка **Run workflow**. Нажми на неё.
4. В маленьком окошке ничего не меняй (там уже выбрано `arm64-v8a`) и нажми зелёную **Run workflow**.
5. Страница обновится. Появится строчка с жёлтым кружочком — сборка пошла. Кружок станет зелёной галочкой через 30–60 минут.
6. Когда появилась зелёная галочка, нажми на эту строчку, прокрути вниз до блока **Artifacts** и скачай **EdgeGram-release.zip**.
7. Распакуй архив. Внутри лежит файл `app.apk`. Это и есть готовое приложение — его можно отправить на телефон и установить.

Всё, ты собрал APK, ничего не устанавливая на компьютер.

## Способ 2: собрать на компьютере

Понадобится Windows-компьютер, минут 40 свободного времени и примерно 10 ГБ места на диске. Интернет нужен: программа скачает несколько гигабайт.

### Шаг 1. Поставь Git

Git — программа, которая скачивает исходный код.

1. Зайди на https://git-scm.com/download/win
2. Скачай установщик, запусти его и везде жми **Next**, потом **Install**.
3. Проверка: нажми `Win + R`, набери `cmd`, нажми Enter. В чёрном окне напиши `git --version` и нажми Enter. Должно ответить что-то вроде `git version 2.x.x`.

### Шаг 2. Скачай проект (важно: вместе с дополнениями)

Открой `cmd` (или PowerShell) и напиши по очереди две команды, каждая — Enter:

```
cd C:\
git clone --recurse-submodules --depth 1 https://github.com/fraylist/EdgeGram.git EdgeGram
```

Что тут важно:

- `C:\` — папка, куда скачается проект. **Не используй папки с русскими буквами и пробелами**, потом будут ошибки.
- `--recurse-submodules` — обязательно. Без этого скачается не всё, и сборка сломается.
- Скачивание займёт 10–20 минут. Это нормально.

**Не скачивай проект кнопкой «Download ZIP»!** В ZIP-архиве нет частей `td`, `ffmpeg` и других, и собрать не получится.

### Шаг 3. Поставь Android Studio

1. Открой https://developer.android.com/studio
2. Скачай, запусти установщик, жми **Next → Install → Finish**. Ничего не настраивай.
3. При первом запуске мастер может предложить скачать SDK — соглашайся, жми **Next** и **Finish**.

### Шаг 4. Открой проект

1. В Android Studio нажми **Open**.
2. Выбери папку `C:\EdgeGram` и нажми **OK**.
3. Внизу побежит полоска и надпись **Gradle sync**. Первый раз это долго: 20–60 минут, качается NDK (около 2 ГБ). Не закрывай окно, просто подожди.
4. Если студия предложит что-то обновить или принять лицензии — соглашайся (**Accept** / **Update**).

Признак того, что всё готово: внизу надпись `BUILD SUCCESSFUL` или просто пропала полоска.

### Шаг 5. Собери APK

1. В меню сверху выбери **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
2. Подожди 5–15 минут.
3. Внизу справа появится окошко с надписью **APK(s) generated successfully**. Нажми там **locate** — откроется папка с файлом.

Готовый файл лежит по адресу:

```
C:\EdgeGram\TMessagesProj_App\build\outputs\apk\afat\debug\app.apk
```

Это и есть приложение. Переименуй его в `EdgeGram.apk`, скинь на телефон и установи.

### Шаг 6. Собери «правильную» версию (не обязательно)

Debug-версия из шага 5 больше по размеру и с отладочной информацией. Если хочешь как в релизе — собери release:

1. В том же меню нажми **Build → Select Build Variant** (или слева вкладку **Build Variants**).
2. В колонке **Active Build Variant** переключи `afatDebug` на `afatRelease`.
3. Снова **Build → Build APK(s)**.
4. Файл появится тут: `TMessagesProj_App\build\outputs\apk\afat\release\app.apk`

## Способ 3: собрать без Android Studio, командой

Для тех, у кого студия не ставится или не хватает места. Нужен JDK 17 и Android SDK.

1. Поставь JDK 17: https://adoptium.net (Temurin 17, Windows x64, `.msi`).
2. Поставь Android Studio — проще всего, она сама поставит SDK. Либо поставь отдельно: скачай `commandlinetools-win` с https://developer.android.com/studio#command-tools, распакуй в `C:\android-sdk\cmdline-tools\latest`.
3. Установи нужные части SDK (в `cmd`):

```
cd C:\android-sdk\cmdline-tools\latest\bin
sdkmanager "platform-tools" "platforms;android-36" "build-tools;36.0.0" "ndk;27.2.12479018" "cmake;3.22.1"
```

4. Создай файл `C:\EdgeGram\local.properties` с одной строкой (двойные косые черты обязательны):

```
sdk.dir=C\:\\android-sdk
```

5. Собери проект:

```
cd C:\EdgeGram
set JAVA_HOME=C:\Program Files\Eclipse Adoptium\jdk-17.0.х.х-hotspot
.\gradlew :TMessagesProj_App:assembleAfatDebug
```

6. APK появится в `C:\EdgeGram\TMessagesProj_App\build\outputs\apk\afat\debug\app.apk`

## Про подпись приложения

Приложение должно быть подписано, иначе Android его не поставит.

- **Для себя** можно собирать как есть: проект сам подпишет тестовым ключом, который лежит в репозитории. Всё соберётся и поставится.
- **Для обновлений** нужен свой ключ: если подпись сменится, Android откажется обновлять приложение и попросит удалить старое (вместе с локальными сохранениями).
- Ключ EdgeGram в репозиторий не выложен специально. В облачной сборке он подставляется из секретов репозитория.

Создать свой ключ можно командой (JDK должна быть установлена):

```
keytool -genkeypair -keystore edgegram.keystore -alias edgegram -keyalg RSA -keysize 2048 -validity 10000
```

Потом укажи его в `TMessagesProj_App/build.gradle` в блоке `signingConfigs`.

## Если сломалось

**`SDK location not found`** — не создан `local.properties`. Сделай его по шагу 4 из способа 3.

**`Cannot find module ... td` / ошибки про ffmpeg** — проект скачан без дополнений. Удали папку и склонируй заново с `--recurse-submodules`.

**`Permission denied` при установке APK** — на телефоне старая версия с другой подписью. Удали старую и поставь новую.

**Студия пишет `Gradle sync failed: Unsupported Java`** — в **File → Settings → Build, Execution, Deployment → Build Tools → Gradle** выбери **Gradle JDK = 17**.

**Сборка падает на C++** — проверь, что NDK именно `27.2.12479018`, а CMake `3.22.1`. Другие версии не подойдут.

**Не хватает памяти** — в `gradle.properties` уменьши строку `org.gradle.jvmargs=-Xmx8g` до `-Xmx3g`.

**Долго и непонятно** — собери способом 1 в браузере. Там ничего не может сломаться на твоём компьютере.
